# Broken Link Building - GroomLocal

> Living document. Last updated: 2026-03-30
> Status: Research complete. Ready for outreach.

---

## How This Works

1. Find dead outbound links on pet grooming school/industry websites
2. Check Wayback Machine to see what the dead page used to contain
3. Match a GroomLocal page (or write new content) as the replacement
4. Email the site owner with the broken link + your replacement

## Tool Recommendations

All agents noted that Exa/web search tools find pages BY CONTENT, not by outbound links. For comprehensive backlink data on dead domains, use:

- **Ahrefs** (Site Explorer > paste dead URL > Backlinks) - most comprehensive
- **Semrush** (Backlink Analytics) - good alternative
- **Moz Link Explorer** - free tier available (limited)
- **DataForSEO Backlinks API** - requires separate subscription activation

Running `findagroomer.com`, `petgroomer.com`, and `dogchannel.com` through Ahrefs would likely surface 100-500+ additional linking pages beyond the 50 found here.

## Notes

- 403 responses (paragonpetschool.com, dogster.com, rover.com/blog) may be bot-blocking, not truly dead. Verify in a browser before outreach.
- `findagroomer.com` (436) was one of the biggest grooming directories. Sacramento Bee and Top Dog Tips both link to it. This is your #1 opportunity.
- Nash Academy moved to nashgroomingschool.com but many sites still link to the old domain.
- ISCC moved to isccmembers.com but many sites still link to isccgrooming.com.
- PNW-specific dead directories (washingtondoggroomers.com etc.) had zero backlink footprint. Skip those and focus on the PNW vet clinic resource pages instead.
- Always check Wayback Machine (web.archive.org) before outreach to understand what the dead page contained.
- The WA Federation of Animal Care page literally asks visitors to report broken links. Start there.
